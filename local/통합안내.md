# 개인용 메이플 탐지기 로컬 통합
사용자가 maple-timer.com 소유자로부터 코드·자산 재사용 허가를 받았다고 진술한 범위에서 공개 프런트엔드를 재사용합니다. 원 저작권 표기는 보존합니다. 제3자 ONNX Runtime·글꼴 라이선스는 별도로 적용됩니다.

## 실행
시작.cmd를 실행하고 http://127.0.0.1:8765 에 접속합니다.
정밀 감지: 원본 브라우저 엔진의 룬·스킬·버프·경험치·부스터·특수코어·PIP.
기존 감지: 기존 프로젝트의 룬·거탐과 수동 타이머.
두 모드는 별도 탭으로 열 수 있으며 화면 공유·설정·PIP는 독립적입니다. 공통 캡처 엔진으로 합친 버전은 아닙니다. 같은 룬을 두 모드에서 켜면 중복 알림이 날 수 있습니다.

## 자산 준비
node local/prepare.cjs 로 공개 정적 파일을 사전 수집합니다.
처음 사용하는 동적 경로는 일반 실행 중 추가 다운로드될 수 있습니다.
local-cache/manifest.json에 원본 URL·시각·SHA-256·크기를 보존합니다.
오프라인시작.cmd는 캐시만 사용하고 누락은 오류로 표시합니다. 모든 설정 조합의 오프라인 준비 완료를 보장하지 않습니다.
정적 리터럴 수집은 실행 코드를 평가하지 않습니다.

## 서버 경계
127.0.0.1에만 바인딩하며 원본 사이트의 정적 자산 GET만 내려받습니다.
캐릭터 조회·원격 처리·문의·제보·통계 API는 제공하거나 프록시하지 않습니다.
정밀모드 CSP는 외부 통신을 차단합니다. 서버 성공 응답을 가짜로 만들지 않습니다.
원본 UI의 서버 기능 버튼은 보일 수 있지만 로컬 실행에서는 지원하지 않습니다.
기존 모드의 텔레그램은 기존 설정에 따라 사용자가 켰을 때 전송됩니다.
공개 서비스 중단/공지 문구는 원본의 기록이며 로컬 엔진의 완전 동작을 증명하지 않습니다.
기존 index.html 직접 열기·GitHub Pages는 기존 기능만 사용합니다. 정밀모드는 로컬 서버가 필요합니다.

## 검증
node --test local/tests.cjs: 자산 경로 제한·해시 검증·오프라인 동작·서버 라우팅.
기존 테스트/저부하감지회귀.js 등은 별도 실행합니다.
브라우저 로딩·모델 실행과 실제 게임 오탐/미탐 검증을 구분해야 합니다.

## 추가 통합: 같은 화면의 기존 거탐
정밀모드 상단의 '기존 거탐 함께 감시'를 켜면 정밀모드에서 사용자가 선택한 동일 MediaStream을 기존 거탐 검출기로도 전달합니다. 별도 화면 선택 없이 240×135 축소본을 300ms마다 분석합니다.
화면을 교체/중지하면 감지 상태를 초기화하며 연결 해제 시 원본 트랙을 임의로 정지하지 않습니다.
거탐은 상단 상태·합성 경고음·한국어 음성으로 알립니다. 원본 PIP 안에 거탐 행을 추가하지는 않았습니다.
기존 모드 전용 설정·PIP와 정밀모드 설정은 여전히 독립적입니다. 별도 기존모드를 동시에 시작할 필요는 없습니다.
