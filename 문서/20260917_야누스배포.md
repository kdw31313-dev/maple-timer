# 야누스 소멸 알림 복구

- 고정 만료 타이머 없음. 우측 상단 아이콘을 확인한 후 부재가 1.2초 이상 지속될 때 주기당 1회 사이트 소리와 텔레그램 요청.
- 처음부터 아이콘이 없으면 알리지 않음. 다시 아이콘이 확인되면 새 주기로 동작. 공유 중단/검은 화면은 만료로 간주하지 않음.
- 최초 인식 3개 관측 및 600ms 확인. 실제 알림 지연은 화면 분석 속도/브라우저 상태에 영향을 받음.
- 야누스 분석은 Worker로 분리. 기존 룬·거탐 판별 파일은 변경하지 않음.
- 두 원본 영상 오프라인 재생은 각 1회 소멸 요청. 첫 영상 표본 8개 사용. 모든 환경에서의 무오류를 보장하지 않음.
- 실제 Chromium 영상 재생을 통해 Worker 연결, 소리 엔진, Telegram 사진 요청을 검증. 원본 HEVC는 테스트 브라우저 미지원이므로 고화질 H.264 사본 사용. 원본과 개인 영상 파일은 공개 저장소에 포함하지 않음.
- Telegram 요청은 테스트에서 가로채 응답했다. 실제 사용자 Telegram 수신 및 스피커 출력은 사용자 환경에서 확인 필요. 브라우저 자동재생 제한/음소거/Telegram 설정에 영향을 받음.
- 상태·Worker 연결·저부하 호출주기·거탐 빠른검사·발동안내·클릭준비·룬 영상 보완 회귀 통과.
- 이전 오탐 개선 후보는 본 배포에서 제외. 야누스는 기본 켜짐.
