# 야누스 소멸 감지 재작성 — 검증 중

## 사용자 요구

- 이전 표본을 활용하되 잘못된 기존 야누스 코드의 전면 재검토.
- 실제 아이콘이 유지되다가 사라질 때 사이트 소리와 텔레그램을 함께 알림.
- 룬·거탐 기능과 이전 미배포 수정은 보존.

## 이번에 작성한 부분

- `js/야누스소멸감지.js`: 기존 상태 판단과 독립된 상태 기계. 기존 종료 임박/숫자 폭 추정/14프레임 알림은 호출하지 않음.
- 최소 3개 관측 및 600ms 이상 활성 확인 후 추적. 회색 종료 위상은 존재로 처리.
- 3개 이상 부재 관측과 1.2초 이상 부재를 모두 만족하면 해당 주기에서 1회 알림 요청. 재사용을 확인하면 새 주기로 재무장.
- 화면 공유 중단, 검은 화면, 해상도 변경, 2.5초 초과 관측 공백에서는 무알림 초기화. 같은 영상 프레임은 중복 관측으로 세지 않음.
- 선택형 야누스 검사: 우측 상단 45% × 높이 24%, 최대 450ms 주기. 룬·거탐을 먼저 처리. 익스트림 골드 검사는 실행하지 않음.
- 실제 소리/텔레그램 발송은 공통 알림 설정과 브라우저·네트워크 상태에 의존함.

## 확인된 범위

- 상태 기계와 운영 어댑터의 자동 테스트: 시작부터 없음, 잠깐 가림, 회색 위상, 완전 소멸, 중복 방지, 재사용, 공유 중단, 초기화, 텔레그램 요청 연결.
- 화면 검사 연결 테스트: 야누스 끔/켬 상태에서 룬·거탐 호출 주기 유지, 야누스 최대 450ms 주기, 같은 프레임 재검사 금지, muted 트랙 초기화.
- 실제 소리 재생과 텔레그램 수신은 아직 검증하지 않음.

## 아직 끝나지 않은 부분

- 아이콘 판별기는 기존 숫자 마스킹 템플릿과 정밀 탐색 코드를 재사용 중. 따라서 전체 판별기의 전면 수정 완료라고 할 수 없음.
- 남은 이전 자료: 야누스 여러 단계 아이콘 템플릿, 2026-07-30 실제 사냥 영상에서 추출했다고 기록된 템플릿.
- 이번 탐색에서 야누스 사용→유지→소멸의 원본 영상을 찾지 못함. 원본이 없는 상태에서 임계값을 바꾸거나 성능을 보장하지 않음.
- 우측 상단 이외로 배치한 버프, 다른 UI 배율, 창 가림/맵 이동의 다양한 사례는 실제 영상 검증 필요. 밝은 다른 창으로 전환된 상황까지 확실히 식별하는 것은 현재 구현하지 못함.
- 동기식 기존 판별기 처리 시간이 룬·거탐의 실제 지연에 미치는 영향도 영상으로 측정 필요. 호출 횟수 검증만으로 CPU 부하나 실시간 지연을 보장하지 않음.
- 사용자에게 현재 설정에서 야누스 전체 주기의 영상 1개 요청함. 추가 자료로 아이콘 판별기를 대조·수정하고 실제 주기 재생 시험 후 적용 여부 판단.
