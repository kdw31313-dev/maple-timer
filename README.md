# 메이플 룬·거탐 저부하 감지기

웹 브라우저의 화면 공유(Screen Capture API)와 Canvas 영상 처리를 이용해 **룬과 거짓말 탐지기에 집중하는 개인용 저부하 감지기**입니다.

---

## 🌟 주요 특징 및 원칙

1. **100% 클라이언트 브라우저 전용 (보안 & 개인정보)**
   - 게임 메모리 탐색, 패킷 감지, 클라이언트 파일 접근이 전혀 없습니다.
   - 키보드/마우스 자동 입력(매크로) 기능이 전혀 없으며, 실제 입력 조작은 100% 사용자가 직접 진행합니다.
   - 화면 분석은 사용 중인 PC의 브라우저 캔버스에서 수행됩니다. 텔레그램 알림을 켠 경우에만 탐지 순간의 사진이 사용자가 설정한 봇으로 전송됩니다.

2. **화면 인식 알림 시스템**
   - **룬 등장 감지**: 미니맵의 분홍 마름모 형태와 고정 배경을 함께 비교합니다. 화면 공유를 시작할 때 이미 떠 있는 룬도 600ms 동안 같은 위치에서 확인되면 알리고, 맵이 바뀌면 배경을 다시 학습합니다. 전투 이펙트가 미니맵을 덮는 동안에도 검증된 룬 추적은 유지하고, 미니맵 아래 전투 UI는 후보에서 제외합니다.
   - **거짓말 탐지기 감지**: 기존 화면 표본과 실제 사냥 영상을 바탕으로 발동 안내·원형 클릭·버섯 안내창·도형 선택·파란 이미지 선택·반투명 숫자·클릭 준비의 7개 유형을 검증합니다. 발동 안내는 고정 좌표나 한 가지 노란색에 의존하지 않고, 화면을 떠다니며 노랑·금색·주황으로 바뀌는 숫자 1줄과 안내문 4줄의 상대 배치를 확인합니다. 클릭 준비형은 전체 화면에서 별빛 패널의 노란 문자 밀도와 고유 색 배치를 함께 찾아 몬스터·공격 이펙트를 제외합니다. 원형형은 화면을 떠다녀도 같은 원 크기·고유 구조가 3회 이어지면 감지하며, 원주 편차·방향·내부 색을 교차 확인해 배경과 전투 이펙트가 만든 가짜 원을 차단합니다.

3. **저부하 집중 처리**
   - 룬은 150ms, 거탐은 300ms 주기를 유지해 반응성을 낮추지 않습니다. Chrome 부하로 영상 버퍼가 잠시 부족해져도 현재 프레임을 그릴 수 있으면 감지를 계속합니다.
   - 야누스·익스트림 골드 자동 분석, 버프 ROI 복사, 학습 사진·영상 수집 모듈은 운영 화면에서 불러오지 않습니다.
   - 거탐 전체 화면 축소 복사도 실제 300ms 검사 틱에만 수행합니다.

4. **수동 사냥 타이머**
   - **경험치 쿠폰 타이머**: 15분 / 30분 / 60분 프리셋 지원. 60초 전, 30초 전, 종료 직후 사운드 & 음성 알림.
   - **재획비·MVP 타이머**: 단순 시간 계산만 수행하며 화면 분석 부하는 발생하지 않습니다.

5. **Picture-in-Picture (PiP) 감지 상태창**
   - 게임 화면 위에 룬·거탐 상태만 간단히 표시합니다.

6. **다양한 알림 모드**
   - Web Audio API 합성음 (차임벨, 비프음, 룬음, 사이렌)
   - 한국어 음성 안내 (TTS: "룬이 출현했습니다!", "경험치 쿠폰 종료 1분 전입니다")
   - 화면 깜빡임 (Visual Flash Overlay)

---

## 🚀 사용법 가이드

1. `index.html` 파일을 웹 브라우저(Chrome, Edge 권장)로 엽니다.
2. 상단의 **`▶ 게임 창 공유 시작`** 버튼을 누른 후 메이플스토리 창을 선택합니다.
3. **영역 지정**:
   - 기본값은 메이플 화면 비율에 맞춘 자동 영역입니다.
   - 화면 배율이나 UI 배치가 다를 때만 룬 범위 지정 버튼으로 조정합니다.
4. 필요 시 **`📺 PIP 감지 상태`** 버튼을 눌러 게임 화면 위에 룬·거탐 상태를 띄웁니다.

## 검출 회귀 검사

보유 스크린샷 원본과 형제 `영상분석도구`의 `sharp` 의존성이 있는 개발 환경에서는 다음 명령으로 검출 회귀를 다시 확인할 수 있습니다. 원본 스크린샷은 개인정보·용량 때문에 배포 저장소에 포함하지 않으므로, 깨끗한 서버 체크아웃에서는 별도 코퍼스 연결이 필요합니다.

```powershell
node "테스트/검출회귀.js"
node "테스트/저부하감지회귀.js"
node "테스트/룬영상보완회귀.js"
node "테스트/발동안내거탐회귀.js"
node "테스트/클릭준비거탐회귀.js"
```

`저부하감지회귀.js`는 별도 사진 없이 실행되며 룬 150ms·거탐 300ms 주기와 버프 분석 0회를 확인합니다. `검출회귀.js`의 실제 사진 검사는 비공개 코퍼스가 연결된 개발 환경에서만 실행됩니다.
