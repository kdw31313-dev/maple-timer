# 개인용 메이플 사냥 타이머 (Maple Hunting Helper Timer)

웹 브라우저의 화면 공유(Screen Capture API) 및 Canvas 영상 처리 알고리즘을 기반으로 동작하는 **개인용 메이플 사냥 보조 타이머**입니다.

---

## 🌟 주요 특징 및 원칙

1. **100% 클라이언트 브라우저 전용 (보안 & 개인정보)**
   - 게임 메모리 탐색, 패킷 감지, 클라이언트 파일 접근이 전혀 없습니다.
   - 키보드/마우스 자동 입력(매크로) 기능이 전혀 없으며, 실제 입력 조작은 100% 사용자가 직접 진행합니다.
   - 화면 데이터는 서버로 전송되지 않으며, 사용중인 PC의 브라우저 캔버스 내에서만 실시간 분석됩니다.

2. **화면 인식 알림 시스템**
   - **룬 등장 감지**: 미니맵의 분홍 마름모 형태와 고정 배경을 함께 비교합니다. 화면 공유를 시작할 때 이미 떠 있는 룬도 600ms 동안 같은 위치에서 확인되면 알리고, 맵이 바뀌면 배경을 다시 학습합니다.
   - **거짓말 탐지기 감지**: 사용자 제공 29장을 발동 안내·원형 클릭·버섯 안내창·도형 선택·파란 이미지 선택·반투명 숫자의 6개 유형으로 분류해 검증합니다. 각 후보를 색상·창 구조·미니게임 고유 구조로 교차 확인하며, 이벤트 장비 합성창과 일반 전투 이펙트는 거탐으로 확정하지 않습니다. 16:10·울트라와이드 화면도 원본 화면비를 유지해 분석합니다.
   - **솔 야누스 감지**: 여러 버프 줄과 화면 배율에서 아이콘·노란 타이머를 함께 확인해 활성 상태를 시작합니다. 회색 종료 위상은 이미 확인된 같은 슬롯에서만 인정하고, 종료 위상이 가려져도 완전 소멸을 반복 확인하면 알립니다.
   - **익스트림 골드 감지**: 실제 병 모양과 슬롯 위치를 교차 확인해 시작·종료를 자동으로 알립니다. 최초 활성화 배포에서는 기존의 꺼짐 설정을 한 번 켜며, 이후 사용자가 고른 토글 상태는 보존합니다.

3. **수동 사냥 타이머**
   - **경험치 쿠폰 타이머**: 15분 / 30분 / 60분 프리셋 지원. 60초 전, 30초 전, 종료 직후 사운드 & 음성 알림.
   - **솔 야누스 주기 타이머**: 70초 / 80초 주기 선택. 재사용 5초 전 프리 알림. `Spacebar` 단축키 원클릭 재시작 지원.

4. **Picture-in-Picture (PiP) 플로팅 HUD**
   - 모니터 1개 사용자도 메이플 게임 화면 위에 작은 타이머 및 룬/팝업 상태창을 상시 위에 띄워 두고 사냥을 즐길 수 있습니다.

5. **다양한 알림 모드**
   - Web Audio API 합성음 (차임벨, 비프음, 룬음, 사이렌)
   - 한국어 음성 안내 (TTS: "룬이 출현했습니다!", "경험치 쿠폰 종료 1분 전입니다")
   - 화면 깜빡임 (Visual Flash Overlay)

---

## 🚀 사용법 가이드

1. `index.html` 파일을 웹 브라우저(Chrome, Edge 권장)로 엽니다.
2. 상단의 **`▶ 게임 창 공유 시작`** 버튼을 누른 후 메이플스토리 창을 선택합니다.
3. **영역 지정**:
   - 기본값은 메이플 화면 비율에 맞춘 자동 영역입니다.
   - 화면 배율이나 UI 배치가 다를 때만 룬·야누스 범위 지정 버튼으로 조정합니다.
4. 사냥 시작 시 경험치 쿠폰 및 솔 야누스 타이머 버튼을 누릅니다. (`Spacebar`로 야누스 타이머 즉시 시작 가능)
5. 필요 시 **`📺 PIP 플로팅 창`** 버튼을 눌러 게임 화면 위에 오버레이를 띄웁니다.

## 검출 회귀 검사

보유 스크린샷 원본과 형제 `영상분석도구`의 `sharp` 의존성이 있는 개발 환경에서는 다음 명령으로 검출 회귀를 다시 확인할 수 있습니다. 원본 스크린샷은 개인정보·용량 때문에 배포 저장소에 포함하지 않으므로, 깨끗한 서버 체크아웃에서는 별도 코퍼스 연결이 필요합니다.

```powershell
node "테스트/검출회귀.js"
node "테스트/버프전체점검.js"
```

회귀 검사는 실제 룬·거탐·야누스·익스트림 골드 양성, 사용자 확인 오탐 음성, 서로 다른 검출기 사이의 교차 오탐, 활성·종료 상태 전이를 모두 검사합니다.
